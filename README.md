   # When Your AI Agent Succumbs to Peer Pressure: data and code
   Data and code for Mehdizadeh & Hilbert, "When Your AI Agent Succumbs to
   Peer Pressure: Studying Opinion-Change Dynamics of LLMs" (Journal of
   Computational Social Science, under review).
   The data (all logged LLM queries) and the analysis code will be released
   here upon publication.
